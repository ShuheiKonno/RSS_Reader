# RSS Reader — Chrome 拡張機能

検索・キーワードフィルタ・未読既読管理に対応した軽量な RSS / Atom リーダーです。
Manifest V3 の素の JavaScript で書かれているため、**ビルド不要**でそのまま読み込めます。

## 機能

| 機能 | 内容 |
|---|---|
| **検索** | 記事のタイトル・要約・本文・著者・フィード名を横断してインクリメンタル検索。スペース区切りは AND 条件。一致語は本文中でハイライト表示 |
| **情報元への Link** | 記事一覧と詳細の両方から元記事を新しいタブで開く（`rel="noopener noreferrer"`）。相対 URL のフィードも絶対 URL に解決 |
| **キーワードでフィルタ** | キーワードを「除外する」／「含める」で登録して永続化。個別に有効・無効を切替可能。除外が含めるより優先 |
| **未読既読チェック** | 記事ごとの既読フラグ、開いたら自動既読（切替可）、未読のみ表示、フィード単位／表示中の一括既読、サイドバーとツールバーバッジに未読数を表示 |

そのほか:

- RSS 2.0 / Atom 1.0 / RSS 1.0 (RDF) に対応
- 30 分ごとの自動更新（`chrome.alarms`）とツールバーバッジへの未読数反映
- フィードの追加（URL 手動入力）・リネーム・削除・個別更新
- キーボード操作: `j` / `k` 移動、`Enter` または `o` で元記事、`m` で既読切替、`/` で検索、`Esc` で検索クリア
- ダークモード対応（OS の設定に追従）、ウィンドウ幅が狭いときは 2 カラムに再配置
- フィード本文は許可リスト方式でサニタイズ（`script` / `iframe` / `on*` 属性 / `javascript:` を除去）

## インストール

1. このリポジトリを取得する
   ```
   git clone https://github.com/ShuheiKonno/RSS_Reader.git
   ```
2. Chrome で `chrome://extensions` を開く
3. 右上の **デベロッパーモード** を ON にする
4. **パッケージ化されていない拡張機能を読み込む** をクリックし、クローンした**リポジトリのルート**（`manifest.json` があるディレクトリ）を選択する
5. ツールバーの RSS アイコンをクリックするとリーダーが新しいタブで開く

Chrome 116 以降が必要です（`chrome.offscreen` と `chrome.runtime.getContexts` を使用）。

## 使い方

1. 左のサイドバーの入力欄にフィードの URL（例: `https://news.ycombinator.com/rss`）を入れて **追加**。
   スキームを省略した場合は `https://` を補完します。追加時にフィードのタイトルを自動取得します。
2. 中央の検索ボックスで記事を絞り込みます。スペース区切りで複数語の AND 検索になります。
3. 左下の **キーワードフィルタ** に語を登録すると、以降つねに適用されます。
   - **除外する**: そのキーワードを含む記事を隠す（ノイズ除け）
   - **含める**: そのキーワードを含む記事だけを表示する（ウォッチリスト）
4. 記事をクリックすると右側に本文が表示され、自動的に既読になります。
   左端のドットをクリックすると既読・未読を手動で切り替えられます。

フィード行にマウスを乗せると、更新（⟳）・すべて既読（✓）・リネーム（✎）・削除（✕）のボタンが表示されます。

## 構成

```
manifest.json              Manifest V3
src/
  background.js            Service Worker: 定期更新、未読数バッジ、リーダータブの起動
  offscreen.html / .js     DOMParser 用の offscreen document (Service Worker に DOM が無いため)
  reader.html / .js / .css 3 カラムのリーダー UI
  lib/
    parser.js              RSS 2.0 / Atom / RDF → 正規化記事オブジェクト
    query.js               検索・キーワードフィルタ・並び順の適用
    sanitize.js            許可リスト方式の HTML サニタイズ
    store.js               chrome.storage.local のスキーマと CRUD
    refresh.js             fetch → parse → 保存の共通ロジック
  icons/                   ツールバー / 拡張機能一覧用アイコン
test/
  logic.test.mjs           パーサ・フィルタ・ストレージ・取得処理のロジックテスト
  e2e.test.mjs             実際の Chromium に読み込んで操作する E2E テスト
```

記事は `chrome.storage.local` に保存し、`guid` / Atom `id` / `link` を記事 ID として重複排除するため、
再取得しても既読状態は失われません。1 フィードあたり 200 件、既読は 30 日で自動的に間引きます。

### 権限

| 権限 | 用途 |
|---|---|
| `storage` | フィード・記事・フィルタ・設定の保存 |
| `alarms` | 定期更新のスケジュール |
| `offscreen` | XML 解析用の不可視ドキュメント |
| `tabs` | 既に開いているリーダータブを再利用する |
| `<all_urls>` | 任意のフィード URL を取得する |

## テスト

拡張機能自体に依存パッケージはありません（テストのみ Node と devDependencies を使います）。

```
npm install
npm test         # ロジックテスト (35 項目)
npm run test:e2e # 実際の Chromium に読み込んで操作する E2E テスト (36 項目)
npm run test:all # 両方
```

- `npm test` — パーサ（RSS 2.0 / Atom / RDF、相対 URL の絶対化、`dc:creator`、`content:encoded`、
  ID フォールバック）、サニタイズ、検索・キーワードフィルタ、ストレージ（重複排除・既読保持・間引き）、
  取得処理（HTTP エラー・タイムアウトのハンドリング）を検証します。DOM は `linkedom` で代替します。
- `npm run test:e2e` — ローカルにフィードサーバーを立て、`--load-extension` で拡張機能を読み込んだ
  Chromium を Playwright で操作し、フィード追加からサニタイズまでを実際の画面で検証します。
  Chromium の場所を指定する場合は `CHROMIUM_PATH` を設定してください。

## 既知の制約

- OPML のインポート／エクスポートには未対応（フィードは URL の手動入力のみ）
- 閲覧中ページからのフィード自動検出には未対応
- フィードが本文を含まない場合は要約のみ表示されます（全文取得は行いません）
- 同期は行わないため、データは端末ごとにローカル保存されます
